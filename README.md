# 地下城：迷踪

一款移动端优先、主打随机事件与迷宫探索的轻量 Roguelike 网页游戏。

当前版本：**1.10.1**。源码仓库包含完整游戏、PNG 素材、回归测试和小红书小工具打包技能。

维护入口：[AGENTS.md](AGENTS.md) · [版本记录](CHANGELOG.md) · [素材说明](assets/README.md)。

## 已实现

- 单层 135×135 大型迷宫，共 18225 个房间，面积约为上一版的 5 倍
- Growing Tree 随机生成与 18%–28% 额外破墙环路，不设定唯一路线
- 玩家从中心出发，整张迷宫最多三个出口；离开后直接结算，不生成第二层
- 三格宽视觉通道，默认两格视野；使用视野道具后关闭主画面迷雾并将地图精确缩小 50%
- 主画面先合并房间与通道，再统一绘制暗红色外边界；共享墙段不再重复叠亮，四通路口的孤立墙柱会直接并入地面
- 完整墙线固定存在，仅由半透迷雾遮挡，不会随移动临时补画
- 右上角缩略图以低饱和灰蓝探索网络为主，仅保留窄暗红墙影，并展示最多三个正南/正北/正东/正西出口方向箭头
- 宝箱、生命泉、陷阱、地图残片、祭坛、遗骸、浓雾、传送阵、石门、盘根裂隙、谷底回声、遗落农具等十二类事件
- 事件描述、敌人遭遇补充和环境记录从文案池按地图种子随机选择，长距离探索会持续出现新的氛围线索
- 地穴鼠、骷髅守卫、毒史莱姆、幽灵、宝箱怪五类敌人，密度随机保持在 4.5%–6%
- 击败怪物有 28% 概率掉落可立即开启的宝箱
- 出口周围两格及最后四个接近房间保持为空，不再放置守卫、怪物或宝箱
- 恢复、视野拓宽、一击必杀、瞬移四类道具
- 血量比较战斗、预计战斗结果、事件时间流
- 战斗预告包含进入敌人房间时的本步毒伤；原地伏击与一击必杀分别按实际规则预测，并明确提示毒伤致命风险
- 事件时间流保留最近 200 条，达到上限后仍持续更新最新记录与未读提示
- 手机滑动与桌面键盘移动；点击主画面或放大地图中的已探索格可自动寻路
- 自动寻路仅经过已探索连通区域，遇到敌人、事件或剧情会安全停止
- 自动保存、继续游戏和个人最远纪录
- 镜头与缓冲区内始终绘制完整迷宫墙体，未知区域仅由半透迷雾遮挡，移动时不再补画墙体
- 游戏结束后展示完整迷宫与本局路线
- 5 种怪物、12 种随机事件和 4 种道具均有两套候选故事；每类首次触发时随机播放其中一段，不显示故事路线标签且本局不重复
- 怪物故事只在首次击败该类怪物后出现，发现或开战时不打断操作；道具故事只在物品实际进入背包后出现，使用初始物品不会触发
- 普通故事采用持久化优先队列：血量记忆 > 击杀怪物 > 随机遭遇 > 拾取道具；每 30 步最多播放一段，冷却期触发的内容会排队且关闭后不会连续弹出
- 当前未读演出单独保存；继续游戏恢复原文而不重新抽取，确认“继续”后才完成该段，不改变原有冷却起点
- 开场和生命降至 75%/50%/25% 时也只随机播放一段线索，逐步披露身份、上山原因与坠谷经过
- 逃离或迷宫内死亡都会用单段完整结局揭示苏醒、自救或搜救过程，并演到村庄终点
- 移动端顶部同时避让原生状态栏和宿主导航工具栏，并结合容器变量、`env()` 与运行时测量修正
- 删除底部方向操作区，主地图与事件时间流直接组成完整纵向布局
- 5×4 透明 PNG 精灵图集，Canvas 与界面共用同一资源
- 全部运行资源本地化，可按轻应用离线 ZIP 规范直接打包

## 运行

项目没有第三方依赖。推荐通过本地 HTTP 服务运行：

```bash
git clone https://github.com/zylcold/dungeon-mizong-game.git
cd dungeon-mizong-game
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

也可以直接打开 `index.html`，核心功能无需联网。

## 轻应用 ZIP

发布包只包含 `index.html`、`styles.css`、`game.js` 与运行时 PNG 图集，入口位于 ZIP 根目录。已移除 Service Worker、Web App Manifest 和所有联网能力，目标语法为 ES2017，并为 Chrome 61 / Android 8.1 提供 CSS 基线回退。

### 小红书打包技能

仓库内附 [minitool-zip-builder 1.6.0](.codex/skills/minitool-zip-builder/SKILL.md)，位于 `.codex/skills/minitool-zip-builder/`。完整保留原始说明、兼容性与容器规范参考文档，以及零第三方依赖的 Node/Python 审计脚本。

来源：[小红书小工具技能包 1.6.0](https://fe-static.xhscdn.com/mini-tool/20260831163932/minitool-zip-builder-1.6.0.skill)。开发或改动小工具前，请先阅读 `SKILL.md` 及对应参考文档；运行审计脚本不能替代代码合规检查与真机验收。

在仓库根目录执行以下命令打包（需要 Python 3 和 `zip`；测试还需要 Node.js）：

```bash
npm test
mkdir -p dist/assets
cp index.html styles.css game.js dist/
cp assets/sprites-atlas.png dist/assets/
python3 .codex/skills/minitool-zip-builder/scripts/audit_artifact.py dist
(cd dist && zip -9 ../dungeon-mizong-minitool-1.10.1.zip index.html styles.css game.js assets/sprites-atlas.png)
python3 .codex/skills/minitool-zip-builder/scripts/audit_artifact.py dungeon-mizong-minitool-1.10.1.zip
```

请使用空的 `dist/` 和尚不存在的 ZIP 文件名进行首次打包；重新打包时先移走旧产物，避免 ZIP 保留旧文件。仅将这份运行 ZIP 上传到小红书容器；GitHub 的 **Download ZIP 是源码包**，包含测试和技能，不能直接作为小工具上传包。构建输出不提交到源码仓库。

## 操作

- 手机：在地图上向四个方向滑动探索未知区域；点击已探索区域自动行走
- 桌面：方向键或 `WASD`
- 点击左侧道具图标可使用道具；视野效果持续 30 步，期间关闭迷雾并缩小 50%，结束后恢复原状
- 点击右上角缩略图可查看放大地图；点击放大地图中的已探索格可开始远距离自动寻路

## 存档

当前游戏和最近个人纪录保存在浏览器 `localStorage` 中，不上传服务器。

1.10.1 与 1.7.0–1.10.0 的进行中存档兼容。载入旧局时会迁移剧情触发标记，并补齐 30 步冷却、待播队列和当前未读剧情字段；个人历史纪录继续保留。旧版本已经丢失的未读演出无法追溯恢复。

## 图集

游戏不使用 SVG 素材。全部角色、敌人、道具和事件图像集中在 `assets/sprites-atlas.png`，规格为 `1400×1120`、5 列×4 行，每格 `280×280`。索引说明见 `assets/sprites-atlas.json`。
